# GreenMoonDev — Studio Website

Static landing site for **GreenMoonDev** indie game studio, hosted on GitHub Pages.

## What's inside

- `index.html` — main landing page
- `privacy.html` — Privacy Policy (linked from Google Play)
- `app-ads.txt` — AdMob authorization file for app verification
- `README.md` — this file

## How to deploy on GitHub Pages

1. Create a new public repository named exactly: `YOUR-USERNAME.github.io`
2. Upload all files from this folder to the root of the repository
3. Go to **Settings → Pages → Source → Deploy from a branch → main / (root) → Save**
4. Wait 1–3 minutes
5. Site will be live at `https://YOUR-USERNAME.github.io/`
6. Verify `app-ads.txt` is accessible at `https://YOUR-USERNAME.github.io/app-ads.txt`

## After deploy

Add the site URL to **Google Play Console → Store settings → Website** field.
Then go to AdMob and click **Check for updates** (may take up to 24 hours).
